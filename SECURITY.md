# Security and responsible use

Do not open public issues containing camera credentials, network diagrams, internal IPs, deployment-specific
robot targets, recorded operator video, controller settings, serial numbers or facility information.

For vulnerabilities, use GitHub's private vulnerability reporting feature if enabled for this repository.
The public source code is not a safety-rated robot controller. Test without physical motion first and perform
site-specific risk assessment, commissioning and supervised path validation before allowing movement.

Never expose robot command or RTDE ports to the public internet; isolate the robot network.
